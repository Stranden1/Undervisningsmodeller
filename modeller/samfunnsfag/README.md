# Samfunnsfag

Her kommer modeller for samfunnsfag. Samme regler som for naturfag (se `AGENTS.md`):
én modell = ett fenomen + én kjent misoppfatning, eleven gjetter først, og en synlig
«Hva modellen forenkler»-boks.

I samfunnsfag bygger modellene ofte på antakelser om hvordan mennesker oppfører seg.
Skriv antakelsene ned i forenklingsboksen, og skill tydelig mellom ekte tall (med kilde)
og det modellen regner ut.

Start en ny modell ved å kopiere `maler/fag/ny-modell/` til
`modeller/samfunnsfag/<modellnavn>/`.

Ingen modeller ennå.
